# Global Risk Portal, desktop preview

A frontend demo of the Global Risk Portal, a risk desk for a trading platform. Every page is one offline HTML file
with dummy data (logins 99000001.., names "Demo Client N", groups under `DUMMY\`). No real data.

Designed and built by Boris Nala. The phone version is in the palantir-challenge repo.

## Open it
Double-click `morning_digest.html`, or serve the folder (`npx serve .`). The nav links open the sibling files.

## Pages
Morning Digest, Risk Analysis, Algo Activity, Watchlist, Open Lots, Client 360, Growth Detection, Top 10, Catches,
News, Notifications, WD Check, WD Approvals, CRA Model, CRA Analysis, Promotion Analysis, Group Spread, PG Markups,
Manual Level, Book View, HouseCleaning, Users, Access, Build Paths, CandleTL Showcase, Sign in.
Algo Config (`index.html`) shows only the WA Sender tab. The other tabs are confidential and not included.

## Deploy
These are static files. On lab.borisnala.com they live under `/risktool-prototype/`.
`_headers` and `robots.txt` keep the pages out of search engines.
